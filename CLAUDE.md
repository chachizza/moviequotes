## High‑Level Architecture
- **React front‑end (src/)** – a Vite‑powered SPA written in TypeScript. The entry point is `src/main.tsx`, rendering `<App />`.
- **App component (`src/App.tsx`)** – manages global state: current quote, active colour palette, selected category, and transition handling. It renders the filter chips, the `QuoteCard`, and the refresh button.
- **Quote data (`src/data/quotes.ts`)** – exports a large array of `Quote` objects, plus helper sets for TV shows, action movies, and comedy movies. Functions:
  - `filterQuotesByCategory` – returns quotes matching a selected `Category`.
  - `getCategories` – derives dynamic categories for a quote based on year and source.
  - `CATEGORIES` constant – the static list shown in the UI.
- **QuoteCard component (`src/components/QuoteCard.tsx`)** – displays a single quote with a 3‑D rotation effect driven by mouse movement. It uses the custom hook `useParticles` to render a particle canvas that follows the card.
- **Particle system (`src/hooks/useParticles.ts`)** – creates a full‑screen `<canvas>` and spawns particles from the edges of the card when the mouse moves. Animation is driven by `requestAnimationFrame`.
- **Styling** – `src/App.css` (not shown) provides the fade‑in/out transition classes and layout.
- **iOS Swift app (Quotes/Quotes/)** – a separate native client consuming the same quote data (bundled as a Swift array or via the generated JSON). It uses Xcode project files; building is handled by Xcode.

## Important Runtime Details
- The front‑end randomly picks a colour palette from `colorPalettes` on each quote change.
- Category chips filter quotes via `filterQuotesByCategory`; the UI updates the current quote when the active category changes.
- Keyboard shortcut **Space** triggers a new quote unless focus is on an input/button.
- Particle canvas is positioned `fixed` with `pointer-events: none` to avoid interfering with UI interaction.
